## 维护原则

同一个问题只允许一份活文档做主入口，其他文档最多引用，不重复承载当前答案。

1. 对外只引用 `AI赋能演示定稿方案`，不要同时引用蓝图、立项沟通和 v1。
2. 开发执行只维护在 `开发指导`，不要把素材清单、seed 格式、页面效果和阶段目标散落到对外方案。
3. 技术实施只维护在 `技术实施定版方案`，不要把 React、FastAPI、模型部署等细节写回对外定稿方案。
4. 通用方法论不绑定巡检项目，不承担巡检项目当前结论。
5. 已归档文档只用于追溯，不再同步更新。
6. 新增 demo 文档前先判断是否能并入当前三类职责，避免再产生平行方案。
7. 活文档引用归档文档时，只能作为历史依据，不要把归档文档写成当前入口。
8. 移动、归档或重命名文档后，必须同步检查相对链接。
