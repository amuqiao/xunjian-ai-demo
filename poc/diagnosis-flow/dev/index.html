单页打磨入口

每个链接把演示状态直接跳到某一步，不用从工作台一路点过来。它们不是四份独立的 HTML —— 那需要把 index.html 的四十多个 script 标签复制四份，加一个组件就要改五处， 迟早漂移。这里走的是同一个 index.html 加一个 URL hash，页面永远只有一个。

人工复核（本 POC 风险最高的一页）

未表决#preset=review-empty L1 结论区变暗、处置路径三条平铺预览 采纳支线#preset=review-accept 自动预选 AI 建议，无分歧条，意见选填 分歧支线#preset=review-divergent 橙色分歧条 + 意见必填 + 执行按钮禁用 执行屏#preset=executed 处置票卡 + 意见回显 + 复测验收 复测退回#preset=retest-failed demo 里唯一的一条回头路

归档与知识库

归档页（未归档）#preset=archive 报告草稿 + 归档去向 + 二次命中锁态 归档页（已归档）#preset=archived 二次命中解锁 知识库#preset=knowledge 分类 / 文档卡片流 / 阅读器 / 入库动画 知识库（含归档报告）#preset=knowledge-archived 归档报告带 NEW 标出现在案例分类里

preset 状态不落盘：刷掉 hash 打开 index.html 就回到正常演示状态。 preset 里的结论、字段取值全部从领域契约现算（"第一条与 AI 建议不同的结论"、 "该字段的第一个选项"），所以换成 domain-pump 或 domain-inspection 之后这些入口 依然可用，不需要改。
