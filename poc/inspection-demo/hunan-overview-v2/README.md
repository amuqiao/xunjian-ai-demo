# hunan-overview-v2 · 湖南省油气管网大屏（巡检站总览）重排版

`hunan-inspection-overview` 的**布局与文案重排版**，不是重构。数据层、3D 层、契约层、
`core` 的四个通用文件、`ui/cards.js` 与 `vendor` 全部用相对路径引用旧目录的原文件，
一行未改，也不复制副本 —— 两边读的是同一份字节，不会各自漂移。旧目录保持可独立运行。

本目录自己新写的只有 4 个 JS + 4 片 CSS：

```
index.html                      加载顺序（旧目录原文件 + 本目录新文件）
styles/01-tokens.css            变量名单与旧目录逐条一致；背景 6 层 → 2 层；新增三档圆角/阴影
styles/02-shell.css             回字形四行；顶栏三列 62px + 居中标题；无底栏
styles/03-cards.css             card-metric / card-chart / ov-table 三族
styles/06-overview-scene.css    回字形五区网格；地图去边框 + 浮层；作业区卡
scripts/core/chartopts.js       3 个 ECharts 构造器（全省口径，无参）
scripts/scenes/overview.js      顶栏 / 指标带 / 左栏三块 / 地图 / 右栏 / 作业区带
scripts/boot.js                 状态机 + render 管线 + 事件委托
verify/verify_overview.py       59 项断言
```

### 四边的分工

| 位置 | 内容 | 下钻时 |
| --- | --- | --- |
| 上 `.ov-stat-band` | 全省 4 个大数 | **不变** |
| 左 `.ov-left-col` | 完成度环 / 质量异常构成 / 台账构成 | **不变** |
| 中 `.ov-map-panel` | 3D 地图，无面板边框 | 相机推进 |
| 右 `.ov-right-col` | 需关注站点清单（整格一块） | 换成该区 |
| 下 `.ov-zone-band` | 6 张作业区卡 | 当前区高亮 |

上、左恒为全省是这版最关键的一条：点开岳阳时全省基准仍在屏上，可以直接对读
「全省 13 个需关注 / 岳阳 5 个」、「全省 95% / 岳阳卡上的 94.4%」。旧版三栏是整块换掉
全省数据，这层对比关系丢了。跟随焦点变化的只有三处：地图相机、右栏清单、下带高亮。
`verify_overview.py` 里「下钻后上带与左栏逐字不变」就是这条设计的可执行断言。

### ⚠️ 地图会缩到约 84%，以及随之而来的成立条件

3D 用固定角度的透视相机，`renderer.setSize(w,h,false)` 只改像素尺寸、不改相机覆盖的
世界范围。所以中段变矮不是把地图裁掉，是**整张地图等比缩小**。而实测省域机位下这块
网格受高度约束（纵向占满容器 91%，横向只用约 740px），高度就是绑定维度：

| | 中段高度 | 地图 |
| --- | --- | --- |
| 三栏（无上下带） | 1130 | 100% |
| 回字形 | 949（容器实测 933） | 约 84% |

这是「地图放中央、避免占满中间」的实现机制，不是副作用。

连带风险：标签的投影间距同步缩到 84%。`styles/05-hunan3d.css` 硬契约第 5 条写明标签盒
52×35.64px、`minDy ≈ 43.6px` 才够排开，而 `engine.js` 的 `sweepLabels` 不是收敛循环
（文件头红线：写成 `while(changed)` 会因浮点误差死锁整页），一趟推不开就是推不开。
所以 **「6 个作业区标签两两不重叠」是这套布局的成立条件**，不是普通断言。实测通过，
但余量很薄：衡阳–湘娄两个标签的纵向中心距只有 24 设计像素（低于 minDy 43.6），
目前不重叠是靠横向拉开的。这一项将来红了，退路顺序是：① 压薄 `.ov-zone-band`
（132 → 100）把高度还给地图；② 还不够就把作业区带挪进侧栏、退回三栏。
**不要去改 3D 机位。**

## 借鉴与不借鉴

参考物是甲方现有系统的截图（`assets/大屏/` 山东公司综合管理与监视平台）。

**借了**：三栏对称 + 地图居中占局部；中间不做面板边框（地图直接浮在底色上，少一个盒子，
从「一张卡」变成「舞台」）；图例浮在地图内（左下角 —— 右下角被 `.ov-zoom` 占了）；
顶栏居中大标题；开篇先讲台账构成（「先交代盘子多大，再讲问题」这个顺序是对的）。

**没借**：每个数字配立体图标 + 发光底座；一屏 10 张卡、每卡 4–6 个数；中英混排、单位
挤括号（`总计(个)`）；四个互不相关的比率各套一个装饰圆环；通栏渐变发光的异形顶栏。

顶栏保留居中标题的代价是**删掉左侧 brand 那两行文字** —— 参考图左上是天气/时间、中间
是标题、右上是机构选择器，没有重复。旧版的问题不是「有居中标题」，而是左 brand
「湖南省油气管网大屏 / 巡检站总览」+ 中间「湖南省油气管网巡检总览」+ 英文 kicker
`HUNAN OIL & GAS NETWORK OVERVIEW` 三处说同一句话。现在标题只出现一次。

从 `dfaft/智能巡检数智员工-演示.html` 借的：三档圆角/阴影、卡片骨架（`sub` 用
`margin-left:auto` 推到标题行右端，省掉一行）、`.stat` 两级排版且**状态色只染数字**
（旧版是整卡描边+背景+发光，三卡同时 warn 时整栏发橙光）、`.num` 等宽数字、动效只留
`fadeUp` + `pulse` 且带 `prefers-reduced-motion`。**不借白底** —— 深色保留，只把背景从
6 层叠加降到 2 层，删掉的四角暗角与扫描线正是把贴边卡片压灰、让整屏发脏的来源。
字号整体上调约 25%：固定画布 2471 宽在 1920 屏上缩放 0.777，旧版 13px 标题落到 10px。

## 「巡检质量保障」卡怎么拆

那张卡原有 9 个数字块（focus 3 + grid 6），每块还带一行小字，背后只有 `quality.js` 的
8 个字段。拆分规则是**每个数只出现一次**：

| 屏上位置 | 回答的问题 | 字段 |
| --- | --- | --- |
| 上带 4 个大数 | 盘子多大 / 分几块管 / 问题多少 / 最紧急 | 站点总数、`zoneTotal`、`issues`、`currentRisk` |
| 左① 完成度环 | 计划做完了吗 | `completionRate`、`completed`、`planned` |
| 左② 异常构成（4 柱） | 异常都是哪几类 | `duration`、`interval`、`offWindow`、`aiAlerts` |
| 左③ 台账构成（2 条堆叠） | 这批站点是什么构成 | `kind`、`medium` 分布 |
| 右 需关注清单 | 具体哪些站点要去 | 逐站 `status` |
| 下带 6 张卡 | 先去哪个区 | 分区需关注数、分区 `completionRate` |

`riskLevel` 与 `p1Issues` 屏上不出现（前者是后三个字段派生的等级标签，后者与
`currentRisk` 只差一个时态，同屏放两个会被当成两件事）。数据层保留这两个字段不动。

三个图表构造器都**不带参数、一律全省口径** —— 左栏恒为全省基准，早先那个恒为 `null`
的 `zoneId` 形参属于死掉的灵活性，已删。

## 需关注站点清单：只列非正常站点

第一版列全部站点，岳阳作业区是 36 行，而那 36 行里「类型」列全是「阀室」、「所在市」
列全是「岳阳市」—— 两整列 72 个格子写着同一个词，正是要治的那种「占位多、字多、
信息少」。改成只列 `danger` + `warn` 之后：省域态 13 行（跨 6 个区），各作业区 1 到 5 行。
总数在卡头 meta（`13 / 141 站点`）。

两种状态的列不同，取的是「哪一列每行都不一样」：省域态 `作业区 / 站点 / 介质 / 状态`，
下钻态 `站点 / 类型 / 介质 / 状态`。「所在市」两种状态都不列 —— 6 个作业区里有 4 个只
覆盖 1 个市。

表是**只读**的：点选站点在这屏没有可见后果（`engine.js` 首页不显示站点柱体，推第三级
相机是旧设计明确排除的），所以不接 `SelectList`，也没有 `state.siteId`。留一个点了没反应
的可选列表，比一个诚实的只读列表更差。

## 下钻的两个入口

1. 地图上的作业区标签 `button[data-hunan-zone]`（原生可聚焦、可回车）
2. 下带的作业区卡 `data-action="select-zone"` + `data-zone-id`；再点同一张 = 弹回全省

⚠️ 卡片**不能**复用 `data-hunan-zone`：`contract.js` 的 `assertPinNamespace()` 会遍历
全文档的 `[data-hunan-zone]`/`[data-hunan-site]`，任何一个落在 `.hunan-labels` 之外就
直接抛错（那两个属性归 3D 标签独占）。验收脚本对这条有专门断言。

返回全省仍只有一个视口入口：地图右下角的 `data-action="back-to-overview"`。
